# 🧠 个人思想库

一个运行在你自己电脑上的网站：**记录你的思想 → 学会你的逻辑 → 用 AI 按你的方式回答**。

- **输入端（思想库）**：把你坚持的**原则**、处理事情的**决策逻辑**、掌握的**知识**和过往**经验**分仓库存进来；也支持直接**导入 txt / Word / zip 文档**，省去手动录入。
- **交互端（智能问答）**：提问时，系统**只从你指定的思想仓库**检索内容，再调用 AI（DeepSeek / OpenAI 等兼容接口），**优先按照你的原则和决策逻辑**选择最合适的路径，最后以你的视角输出回答。

## 快速开始

1. 双击 **`启动网站.bat`**（或桌面「个人思想库」快捷方式；需已安装 Node.js）。
2. 浏览器自动打开 `http://localhost`。
3. 先建几个**思想仓库**（如：工作、投资、学习），到「📚 思想库」录入想法或**导入文档**。
4. 到「⚙️ 设置」填写 AI 接口密钥（默认填好 DeepSeek 地址）。
5. 到「💬 智能问答」，**点选本次要抽取的仓库**后提问。
6. 想停止时，双击 **`停止网站.bat`**。

> 没填密钥也能用：问答会进入**演示模式**，展示本地检索结果。

## 多思想仓库

- 在「📚 思想库」顶部的仓库条上点击 **＋ 新建仓库**，可创建任意多个仓库（如：工作、投资、健康、技术知识），每个仓库独立管理不同领域的知识。
- 每条思想都属于一个仓库；录入/编辑思想时可选择所属仓库，卡片上会显示仓库标签。
- **问答时**：输入框下方选择本次要抽取的仓库（可多选）。**只从所选仓库检索**，其他仓库的内容不会进入回答；不选则使用全部仓库。
- 删除仓库不会丢思想——其中的思想会自动移入「默认仓库」。

## 文档导入（txt / Word / zip）

在「思想库」右上角点 **📄 导入文档**，或打开"记录思想"弹窗后点 **📄 导入文档**：

| 格式 | 行为 |
| --- | --- |
| `.txt` / `.md` / `.log` / `.csv` | 自动识别 UTF-8 / GBK 编码，提取为一条思想（可在弹窗里先预览再保存） |
| `.docx`（Word） | 自动解包并提取正文，段落保留 |
| `.zip` | **批量导入**压缩包内所有 txt / md / docx 文件，每个文件成为一条思想 |
| `.doc`（旧版） | 暂不支持，请另存为 .docx 或 .txt |

单条思想最长 5 万字，超出部分自动截断并标注。

## 数据都在本地项目目录

```
thought-library/
├── server.js           # 本地服务器（纯 Node.js，零第三方依赖）
├── config.json         # AI 接口配置（密钥只存在这里）
├── make-icon.js        # 大脑图标生成脚本
├── data\               # ★ 你的全部数据
│   ├── repos.json          # 思想仓库
│   ├── thoughts.json       # 思想库
│   ├── conversations.json  # 问答历史
│   └── study.json          # 学习模式存活率
├── public\             # 网页前端
├── 启动网站.bat / 停止网站.bat
```

- 不装任何 npm 包、不写数据库，代码 + 数据全部在本项目目录，系统盘零占用。
- 服务器只监听 `127.0.0.1`，只有你这台电脑能访问，思想是私密的。

## AI 接口配置

在「设置」页填写（也可直接编辑 `config.json`）：

| 配置项 | 说明 |
| --- | --- |
| 接口地址 Base URL | 兼容 OpenAI 的地址，如 `https://api.deepseek.com/v1` |
| API 密钥 | 对应平台的 Key（DeepSeek：https://platform.deepseek.com ） |
| 模型名称 | 如 `deepseek-chat`（DeepSeek-V3）、`gpt-4o`、`qwen-plus` 等 |
| 温度 | 0–1，越高回答越发散 |
| 检索条数 | 每次问答注入提示词的思想条数（1–20） |
| 对你的称呼 | 思维分身会以你的身份口吻回答 |
| 自定义系统提示词 | 可选，追加在默认提示之前 |

## 问答如何"学会"你的逻辑

每次提问时，服务器会：
1. 在你的**所选仓库**内对问题分词检索最相关的若干条（**决策类问题**优先加权"决策逻辑/原则"分类，重要思想额外加权）；
2. 把检索到的内容注入系统提示词，作为回答的**第一依据**，并明确本次检索范围；
3. 调用 AI 流式生成回答，末尾附【思考路径】说明调用了哪些仓库与思想、为什么这样选；
4. 回答下方列出**参考了哪些思想**（悬停可见仓库与分类），点一下即可跳转查看/修改；也可一键**把问答存入思想库**。

## 备份

「设置」→「数据管理」可**导出/导入备份**（JSON 文件，包含全部仓库、思想与对话），或直接复制 `data\` 文件夹。

## 🎓 学习模式

在左侧菜单栏进入「学习模式」，用你的思想库做**主动回忆训练**：

- **学习范围**：选择要复习的仓库（可多选，不选则全部）；系统按优先级挑知识点（未掌握 > 已到期 > 从未学过 > 薄弱 > 存活率低）。
- **四阶段循环**：
  1. **主动出题**——教练从知识点出带「陷阱」的简答题/推导题，末尾标注知识库位置，方便核对；
  2. **思维对抗**——答错时教练扮演「杠精」，用知识库原文指出逻辑漏洞；反驳成功则认可，失败则引导回忆；
  3. **极限压测**——答对后修改约束条件（换场景）出更难的题，考察是否真正理解底层逻辑；
  4. **存活率监测**——系统在后台对作答另行判分并更新存活率。
- **存活率规则**：初始 0；答对 +20，连续答对 3 次达 100 →「已掌握」每 3 天复习；答错 -30，存活率 <60 →「薄弱」进高频队列每 1 小时复习；其余每 1 天复习。
- **操作按钮**：`▶ 开始学习`、`💡 给提示`（只给 1 个关键词）、`📺 纠正字幕错误`、`🏁 结束学习`（输出学习报告）。
- 右侧「知识点与存活率」面板可看到每个知识点的存活率条、已掌握/薄弱/未学标记，点击某项直接开始学习该点，可单独重置。
